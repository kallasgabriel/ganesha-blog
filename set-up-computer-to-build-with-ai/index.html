Set Up Your Computer to Start Building with AI

A 30-minute setup for non-technical beginners: the four things you need to start building with AI, what you can safely skip, and how to test it works.

To start building with AI as a non-technical beginner, you need four things: a modern web browser, one AI assistant account, a dedicated folder on your computer with a clear naming rule, and a free place to publish when you are ready. Plan about 30 minutes for the whole setup. You do not need to install a programming language, buy a new laptop or learn any command line to get your first project working.

Most setup guides online assume you want to become a developer, so they start with a code editor, a repository and a local server. That is a real setup, but it is the wrong first step if your goal is to get one small idea working this week. Below is the lighter version, plus the list of things you can safely postpone.

What you actually need

Four items, in the order you should get them:

  • A current browser. Chrome, Edge, Firefox or Safari, updated. This is where most AI builders run, and it is also where you will open and test whatever you create. Keep one browser as your "work" browser so your logins are always in the same place.

  • One AI account, not five. Pick a single assistant or builder and stay with it for your first project. Switching tools mid-project is the most common reason beginners lose track of their files and their context. You can compare tools after you have finished something.

  • A dedicated folder with a naming rule. Create a folder called ai-projects in your Documents, and inside it one folder per project: ai-projects/task-app, ai-projects/recipe-page. Every file the AI gives you goes into the matching project folder, never in Downloads.

  • An account where you can publish. Free hosting services let you drag a folder in and get a public link. You do not need it on day one, but having the account ready removes the excuse later. We cover the publishing step separately in our guide on how to publish a website you built with AI.

What you can skip for now

This is the part most guides get wrong. For your first two or three projects, you can ignore:

  • Programming languages and runtimes. No Python, no Node.js installation. If a tutorial starts with "install Node", it is aimed at a different reader.
  • A code editor. Notepad or TextEdit can open any file the AI gives you if you ever need to look inside. A real editor becomes useful when you have more than a handful of files.
  • Version control. Useful, and worth learning eventually. On day one it adds vocabulary you do not need. Use the backup method below instead.
  • A paid plan. Start free. Upgrade when you hit a limit you can name.
  • A domain name. Free hosting gives you a working link. Buy a domain when something is worth the address.
  • A new computer. The AI runs on someone else's servers. Yours mostly needs to open a browser.

The 30-minute setup, step by step

  1. Update your browser (2 min). Open the settings menu, let it update, restart it.
  2. Create your AI account (10 min). Use an email you check. Confirm it. Open the tool and send one throwaway message so you know the interface responds.
  3. Build your folders (5 min). Documents → ai-projects → one folder for your first project. Name it in lowercase with hyphens, no spaces: task-app, not Task App (final)(2). Spaces and accents cause broken links when you publish.
  4. Write your project brief (5 min). One text file in the project folder, named brief.md. Template below.
  5. Run a test project (10 min). See the check further down.
  6. Set your backup rule (2 min). Every time something works, copy the whole project folder and rename the copy with the date: task-app-2026-10-20. That is your undo button when the AI breaks a working version.

A project brief you can copy

Save this as brief.md in your project folder and fill it in before your first prompt. It takes five minutes and it is the file you will paste back into the chat every time the AI loses the plot.

# Project: recipe page

What it is: a single web page that shows my 10 favourite recipes.
Who opens it: friends, on their phones.
It must: show a list of recipe names, open the full recipe when tapped,
         work without internet after it loads.
It must not: need a login, need a database, need me to install anything.
Done means: I can open the file in my browser on my phone and read a recipe.
Files: everything stays in one folder, one HTML file if possible.

Then your first prompt is simply: "Here is my project brief. Build the first version as a single HTML file I can save and open in my browser. List the files you are giving me and tell me exactly where to save each one." That last sentence is what turns an impressive answer into something you can actually open. If you want to go deeper on phrasing, see how to write an AI prompt that builds what you want.

How to check your setup actually works

Do not test your setup with your real idea. Test it with something you can judge in two minutes:

  1. Ask the AI for a one-page site that shows your name and three links.
  2. Save the file it gives you into your project folder, exactly with the file name it told you.
  3. Double-click the file. It should open in your browser and look roughly like what you asked.

If it opens: your setup is done, and you now know the full loop — ask, save, open, check. If it does not open, the cause is almost always one of three things: the file was saved as .txt instead of .html, the files ended up in different folders, or you opened the file in a text program instead of the browser. Fix those before concluding anything about the AI.

This ask-build-test-correct loop is the whole method, and it is what the beginner course on turning ideas into real projects with AI practises step by step, starting with preparing your working environment and moving through a web page, a task app and an automation.

Three mistakes that cost beginners their first week

  • Collecting tools instead of finishing a project. Watching five tool reviews feels like progress. Finishing one ugly page is progress.
  • Leaving files in Downloads. Files scattered across Downloads, Desktop and a cloud folder is the number one reason a project "stops working" for no visible reason.
  • No copy of the last working version. When the AI rewrites something that already worked, you want a dated folder to go back to. Thirty seconds of copying beats an hour of re-prompting.

Your setup is not a milestone. It is the twenty minutes that stops being interesting the moment you have something open in a browser — which is exactly the point.

Frequently asked questions

Do I need to install a programming language or a code editor to start? No. For your first projects, a modern browser, one AI assistant account, a dedicated folder on your computer and a free hosting account are enough. Browser-based AI builders run the code for you, and a chat assistant can hand you files you simply save and open. Install a code editor later, only when a project outgrows copy and paste.

How long does the setup take? Plan about 30 minutes: roughly 10 minutes to create your AI account, 5 minutes to create your folder structure, 5 minutes to write your project brief and 10 minutes to run a test project. You do this once, not for every project.

Is my computer good enough to build with AI? Almost certainly yes. The heavy work happens on the AI provider's servers, not on your machine. If your computer runs a current version of Chrome, Edge, Firefox or Safari without freezing, it is good enough. A stable internet connection matters more than your processor.

Do I need to pay for an AI tool on day one? Start on a free tier and see where it stops being enough. The usual limits you will hit first are the number of messages per day and the size of a project the tool can hold. Upgrade only after you have finished one small project and know which limit is actually blocking you.

What is the first sign my setup is not working? You cannot open your own result. If the AI gives you files and double-clicking the main file does not open anything in your browser, the problem is usually a wrong file name or extension, or files saved in different folders. Fix that before blaming the AI's code.
